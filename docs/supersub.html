Superscript & Subscript

HTML provides two special tags for displaying text above or below the normal text line.

Superscript (<sup>)

The <sup> tag displays text slightly above the normal line. It is commonly used for mathematical powers, exponents, and ordinal numbers.

Examples

(a + b)2

x3 + y2

Today is my 21st birthday.

Subscript (<sub>)

The <sub> tag displays text slightly below the normal line. It is commonly used in chemical formulas and mathematical notation.

Examples

H2O

CO2

CH4 + 2O2 → CO2 + 2H2O

Explanation

Superscripts are used whenever text needs to appear above the normal writing line, while subscripts place text below it. These tags are especially useful in mathematics, chemistry, and scientific writing.

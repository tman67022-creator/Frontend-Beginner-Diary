Semantic HTML

Semantic HTML uses tags that describe the purpose of the content instead of simply changing how it looks. These tags make webpages easier to understand for browsers, search engines, and screen readers.

<header>

The <header> tag usually contains the title, logo, or introductory content of a webpage or section.

<main>

The <main> tag contains the primary content of a webpage. There should normally be only one <main> element on a page.

<section>

The <section> tag groups related content together into logical sections.

<article>

The <article> tag is used for independent pieces of content, such as blog posts, news articles, or forum posts.

<aside>

The <aside> tag contains information related to the main content but not essential to it. Examples include side notes, advertisements, or recommendations.

<footer>

The <footer> tag usually contains copyright information, contact details, or navigation links found at the bottom of the page.

<nav>

The <nav> tag contains navigation links that help users move between pages of a website.

Why Use Semantic HTML?

  • 📖 Makes your code easier to read.
  • 🔍 Helps search engines understand your website.
  • ♿ Improves accessibility for screen readers.
  • 🛠️ Makes websites easier to maintain.

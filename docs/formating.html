Text Formatting in HTML

HTML provides several tags that allow you to change the appearance of text. Below are some of the most commonly used formatting tags.

Bold Text

The <b> tag makes text appear bold.

Example: This sentence is bold.

Italic Text

The <i> tag displays text in italics.

Example: This sentence is italic.

Underlined Text

The <u> tag underlines text.

Example: This sentence is underlined.

Strikethrough Text

The <s> tag draws a line through text.

Example: This sentence has been crossed out.

Big Text

The <big> tag displays text slightly larger than normal.

This text is bigger.

Small Text

The <small> tag displays text smaller than normal.

This text is smaller.

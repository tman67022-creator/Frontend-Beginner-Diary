The <pre> Tag

Normally, HTML ignores extra spaces and line breaks. The <pre> tag tells the browser to display text exactly as it appears in the HTML file.

Example

        This line starts here.
            This one is indented.
                This one is indented even more.

        Spaces and line breaks are preserved.

Another Example

        Roses are red,
            Violets are blue,
        HTML is fun,
            And coding is too.

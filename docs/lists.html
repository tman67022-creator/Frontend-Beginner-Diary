Lists, Tables and Forms

On this page I will be documenting what I learned about Lists, Tables and Forms in HTML.

Lists

HTML provides two main types of lists: Ordered Lists and Unordered Lists. Lists can even contain other lists, creating nested lists.

Ordered Lists

Ordered Lists are created using the <ol> tag. Each item is automatically numbered.

Example:

  1. First Item
    1. A Sub Item
    2. Another Sub Item
    3. And a Third One
  2. Second Item
  3. Third Item

Ordered Lists can also use letters or Roman numerals instead of numbers.

Capital Letters

  1. First Item
  2. Second Item
  3. Third Item

Small Letters

  1. First Item
  2. Second Item
  3. Third Item

Capital Roman Numerals

  1. First Item
  2. Second Item
  3. Third Item

Small Roman Numerals

  1. First Item
  2. Second Item
  3. Third Item

Unordered Lists

Unordered Lists are created using the <ul> tag. Instead of numbers, bullet points are displayed.

Example:

  • First Item
    • A Sub Item
    • Another Sub Item
    • And a Third One
  • Second Item
  • Third Item
  • Fourth Item

Tables

Tables are useful for displaying data in rows and columns. Four main tags are used:

  • <table> – Creates the table.
  • <tr> – Creates a table row.
  • <th> – Creates a heading cell.
  • <td> – Stores table data.

Tables can also use features such as <caption> and colspan.

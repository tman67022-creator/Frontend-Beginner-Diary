HTML also allows us to embed videos using the <video> tag.

Yeah... it's a Homelander edit. I know, edgy. I could have added controls to the video, but I personally think it looks cleaner without them.

One thing I learned is that the <video> tag is not self-closing like the <img> tag. It requires both opening and closing tags; otherwise, anything after it may not display correctly.
